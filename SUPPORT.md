# Support

Thanks for using futuapi4go. Here is where to get help.

## Where to ask

| I want to... | Go to |
|--------------|-------|
| Report a bug | [GitHub Issues](https://github.com/shing1211/futuapi4go/issues/new?template=bug_report.yml) |
| Request a feature | [GitHub Issues](https://github.com/shing1211/futuapi4go/issues/new?template=feature_request.yml) |
| Ask a usage question | [GitHub Discussions](https://github.com/shing1211/futuapi4go/discussions) |
| Report a security issue | [SECURITY.md](./SECURITY.md) — **do not** open a public issue |
| See runnable examples | [futuapi4go-demo](https://github.com/shing1211/futuapi4go-demo) |

## Before you ask

Please check, in order:

1. [README.md](./README.md) and the [docs/](./docs/) set, especially
   [docs/USAGE.md](./docs/USAGE.md) and [docs/VERSION_MAP.md](./docs/VERSION_MAP.md).
2. The README "Troubleshooting" table.
3. Existing [issues](https://github.com/shing1211/futuapi4go/issues) and
   [discussions](https://github.com/shing1211/futuapi4go/discussions).
4. The official [Futu OpenAPI documentation](https://openapi.futunn.com/futu-api-doc/en/).

## What to include in a bug report

- `go version`
- futuapi4go version (commit SHA or tag, e.g. `v0.19.3`)
- Futu OpenD version / protocol version (see [docs/VERSION_MAP.md](./docs/VERSION_MAP.md))
- Whether you use simulate or real trading
- A **minimal reproduction** (smallest code + exact command)
- Full error output, with secrets redacted

## Scope

This project is maintained on a best-effort basis by volunteers. There is no
commercial support or SLA. Requests that are out of scope may be closed.

> **Trading risk:** this is a programming library, not investment advice. See
> [DISCLAIMER.md](./DISCLAIMER.md). Always test in simulate mode before trading
> with real funds.
